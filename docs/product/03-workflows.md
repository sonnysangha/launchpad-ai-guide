Launchpad offers two workflow choices for the first sample project.

Client Delivery is for a fictional service or creative deliverable, such as a website or brand refresh. Its sample tasks help you define a brief, make the deliverable, review it, and prepare a handoff.

Campaign is for a fictional marketing launch. Its sample tasks help you define the audience and campaign brief, make campaign assets, review them, and prepare the launch handoff.

Both workflows use the same four board stages: Brief, Build, Review, and Handoff. The choice determines the sample project's workflow and example tasks; it does not send messages, publish a campaign, or connect external tools. Use client_delivery or campaign in the draft tool. The user confirms the choice using Create in the browser.

Preview displays the chosen workflow's six unsaved sample tasks. After Create, Board and List display the same saved tasks. Selecting Review in List or Preview filters the visible task rows; it does not move or modify a task.
