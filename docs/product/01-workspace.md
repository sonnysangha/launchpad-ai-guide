Launchpad is a fictional client-project manager for a local demonstration. Use invented business and project names, never real customer information.

A workspace groups your sample project. Choose a business or workspace name between 2 and 80 characters. The guide can put a name you provide into the draft form. You can also edit the form directly.

During onboarding, the project area has Setup and Preview views. Setup contains the unsaved form. Preview shows sample task rows for the chosen workflow before you create anything. The project sidebar returns to these views; after creation it uses the saved project name and opens Board and List.

People is in the sidebar. Help center is in its footer, with searchable answers about workflows, roles, and Handoff. The voice guide lives in a separate corner widget and can show these views or answer questions.

Draft changes are not saved projects. Review the workspace name, first project name, and workflow, then press Create in the browser to save. The voice guide cannot press Create or persist your workspace. Incomplete setup returns to onboarding after sign-in; completed setup opens your project's Board.
