Your first project is a fictional example that belongs to your signed-in account's workspace. Choose a project name between 2 and 80 characters, such as Orbit brand refresh. Choose either Client Delivery or Campaign as the workflow.

The guide can update the live draft and highlight the next setup step. These actions do not create anything. Check every field and press Create yourself to save the workspace and one sample project with sample tasks. A spoken yes does not save the project.

Before creation, Setup holds the draft and Preview displays the selected workflow's six sample task rows. Preview is unsaved; inspecting or filtering it does not create a project.

After creation, the sidebar uses the saved project name. Board and List are two views of that same saved project's tasks, starting with six samples. Board groups tasks into stage columns. List shows task rows and can filter by stage. Refreshing or signing in again preserves the saved project. Sample tasks are demonstration data, not real customer work. The guide never creates additional projects or claims that an unsaved draft has been saved.

Once the project is saved, you or the guide can add new tasks. For example, ask: Add a task called Design homepage. A new task is saved immediately after the visible Add task action succeeds. This is separate from initial workspace creation; the guide still cannot create a workspace or an additional project.
